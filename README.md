# Kali Combined Monorepo

Toto je kombinované repo obsahující tři samostatné projekty Kali ekosystému.

## Struktura

```
kali_combined/
├── kali_core_emulator/     # Core emulator project
├── kali_ai_assistant/      # AI assistant module
└── kali_GUI/               # GUI interface
```

## Projekty

### 1. kali_core_emulator
- **Jazyk**: Primárně C (82.4%)
- **Repository**: https://github.com/zombiegirlcz/kali_core_emulator
- **Popis**: Základní emulator pro Kali systém

### 2. kali_ai_assistant
- **Jazyk**: Kotlin (75.6%), Python (22.3%)
- **Repository**: https://github.com/zombiegirlcz/kali_ai_assistant
- **Popis**: AI asistent modul pro Kali

### 3. kali_GUI
- **Jazyk**: Primárně C (86.9%)
- **Repository**: https://github.com/zombiegirlcz/kali_GUI
- **Popis**: Grafické uživatelské rozhraní pro Kali

## Instalace

Každý projekt si lze klonovat jednotlivě z odkazů výše, nebo si lze stáhnout tento monorepo a pracovat s jednotlivými moduly v jejich adresářích.

## Poznámky

Jednotlivé projekty si udržují svou vlastní historii commitů a konfiguraci v jejich vlastních repozitářích.
